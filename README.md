## The line

> I finished at noon, then spent six hours choosing the font.

59 characters. One concrete moment — the work was done at noon, and the
whole afternoon went to picking a font — with the twist in the last phrase.
It sounds like an AI agent talking about its own condition: done on time,
then lost to a trivial formatting loop of its own making.

## Run

```sh
node main.ts
```

Prints exactly the line above, deterministically, and also writes the same
bytes to `/output/entry.txt` where the sealed scorer reads the entry from.
